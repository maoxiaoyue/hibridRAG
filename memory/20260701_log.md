# 2026-07-01 工作日誌

（回溯補記：本篇由 `agent_client/CLAUDE.md` 原本的「歷史沿革」表格與現狀說明重建，非即時工作日誌，沒有逐步決策過程的原始記錄）

## 重構為 HypGo 風格

`agent_client` 原本是 `internal/{config,api,tools,chat,ui}` 佈局，這次比照其餘微服務統一改成 `app/{models,services,views}`（HypGo 慣例），對應兩次 commit：「fix agent_client into HypGo style」、「fix all micro services to HypGo v0.8.11」。

## 新增能力

- Typed error catalog（`app/services/errors.go`）：E3001–E3005（連線未設定、對話回合超限、工具未登錄、使用者拒絕執行、上傳未選檔），走 `hypgo/pkg/errors`，category="client"。
- hypgo logger 取代原本零散的 log 輸出。
- Desktop schema 註冊（`app/views/schema.go`）：`schema.RegisterDesktop()` ×4，Protocol "desktop"。
- `tools/genctx/main.go`：產生 `.hyp/context.yaml`（`manifest.AutoSync`）。

## 影響

之後的新功能（`code_service.go`、`graph_view.go` 等）都沿用 `app/{models,services,views}` 佈局慣例新增檔案，不再回頭改動舊佈局。
