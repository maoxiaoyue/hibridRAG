# 2026-07-09 工作日誌 — mobile_client：pub_client 功能的 Android 手機版

## 需求

「把 pub_client 的功能，再做一個 Android 手機版本。」

## 方案選擇

pub_client 本身是 Go + Fyne，而 Fyne 官方支援 Android（gomobile 打包）——所以不換技術棧、
不寫 Kotlin，直接建一個**新的獨立 module `mobile_client/`** 移植功能。三個候選方案的取捨：

| 方案 | 為什麼不 / 為什麼是它 |
|------|--------------------|
| (a) pub_client 內加 build tags 直接雙平台 | DuckDB（無 Android binding）、Win32 原生對話框、registry device_id、hypgo 依賴全要 tag 隔離，侵入面太大、容易弄壞已可用的桌面版 |
| (b) 原生 Kotlin app | 整套 gRPC/DTO/UI 邏輯重寫，工程量最大，且與現有 Go codebase 無法共享心智模型 |
| **(c) 新 module 移植（採用）** | proto/pb 拷貝即可共用契約；services/views 平行移植、改動點集中在平台差異；桌面 `go build` 可直接跑同一套 UI 做開發驗證 |

## 功能範圍

移植：Chat（ChatStatus 輪詢、Stop、附圖視覺辨識、RAG ID 切換、session 歷史）、
Upload（多檔累積 + job 輪詢 + Verify）、Graph（關鍵字/語意搜尋、force-directed 區域圖、
關鍵節點自動選取、待審關係 Approve/Reject）、Settings（Gateway + API Key + Test Connection）。

**不移植**（手機上不適用）：本機工具 allowlist execv、內建 Coding Agent、Sync Vault。
engine 防禦：server 若回 `tool_calls`，逐一回「此裝置不支援本機工具」IsError 結果並續推理，
不會卡死（`chat_service_test.go::TestSend_ToolCallsDeclined` 驗證）。

## 平台替代（三個關鍵差異）

1. **儲存**：DuckDB 加密庫 → `app/store` AES-256-GCM 加密 JSON（`config.enc`/`sessions.enc`
   + 隨機 32B `store.key`，放 Fyne app 私有目錄 `a.Storage().RootURI().Path()`）。
   威脅模型同桌面版 fallback 路徑（檔案+金鑰同目錄，靠 Android 沙箱隔離其他 app）。
   sessions 上限 100 條自動修剪。測試驗證 API Key 不會明文落地。
2. **device_id**：Windows MachineGuid → 首次啟動 `and_` 隨機 ID 持久化（純 Go 拿不到
   ANDROID_ID，需 JNI 不值得）；重灌視同換機，`gateway apikey unbind` 重綁。
3. **選檔**：Win32 對話框（路徑）→ Fyne dialog + SAF `content://` URI，內容當場讀進
   記憶體（`file_pick.go`，單檔 64MB 上限對齊 gateway）；附圖縮圖/上傳全改 (name, data) 傳遞。

## UI 調整（手機直式）

- 主導覽：`AppTabs` 手機時 `TabLocationBottom`（桌面驗證時開 420x780 直式視窗模擬）
- Graph 頁：桌面的 HSplit 左右分割 → 內層 AppTabs 四子頁 Results / Graph / Details / Review；
  選結果自動切到 Graph 子頁
- graph_widget 互動改觸控模型：`desktop.Mouseable`（MouseDown/Up）→ `fyne.Tappable`（點選）
  + `Draggable` 第一個事件 hit test 決定拖節點或 pan；縮放加 `ZoomBy` +/- 按鈕（無滾輪）；
  觸控命中半徑放寬 8px；保留 `Scrolled`（桌面開發用）
- Chat 頁按鈕全改 icon（窄螢幕）；物理滑桿（Repel/Spring/Dist）不搬（手機沒空間，用預設值）

## 中文字型（Android 特有坑）

Android 系統中文字型幾乎都是 `.ttc`（`NotoSansCJK-Regular.ttc`），Fyne 的 go-text
`ParseTTF` 不吃 TTC。解法：`theme.go` 三層 fallback——**內嵌字型**（`app/views/fonts/`
go:embed，放一個 NotoSansTC TTF 即可靠）→ `FYNE_FONT` → 系統候選清單；每個候選先用
go-text 預解析驗證（`parseableFont()`），解析失敗跳過而不是讓渲染層爆掉。

## 踩坑：fyne v2.4.5 打不出 Android 包

`fyne package -os android/arm64` 報 `could not determine what C.ALooper_pollAll refers to`
——NDK 26+ 移除了 `ALooper_pollAll`，fyne v2.4.x 的 Android driver 還在用（本機只有 NDK 29）。
**解法：mobile_client 升 fyne v2.5.5**（桌面版 pub_client 維持 v2.4.5 不動）。v2.5 仍允許
goroutine 直接更新 widget（v2.6 才強制 main thread），移植程式碼不用加 `fyne.Do` 包裝。
升級後 build/test 仍全綠，APK 打包成功。
